# Content Engineering

This repository supports Ultrathink, one of our key franchises.

Ultrathink is a weekly AI newsletter that arms modern executives with the tools, frameworks, and tactics they need to lead an AI-native enterprise. Our goal is to make Ultrathink the #1 applied AI newsletter for business decision-makers.

## Repository goals

We use this repository for two related purposes:

1. Critique and analyze Ultrathink’s editorial approach, including its structure, voice, arguments, recurring sections, and opportunities to improve.
2. More commonly, write new issues once we have the full scope and ideas. New issues should extrapolate from and improve upon the three existing examples while remaining recognizably Ultrathink.

## Editorial examples

The `examples/` directory contains three prior issues in a plain-text format:

- `example1_raw.md`
- `example2_raw.md`
- `example3_raw.md`

Together, these examples form the initial editorial reference set for analyzing the franchise and developing future issues.
